## Lokal

Open-source tools that make AI coding agents work correctly for Indonesia, and keep people's personal data out of the model.

- **[lokal](https://github.com/lokal-id/lokal)**: skills, an MCP server, and a privacy guard for Claude Code, Cursor, Codex, Gemini CLI, and any MCP client. Official region data down to the village, postal codes, holidays, NIK/NPWP and phone validation, Rupiah, QRIS, and Samaran, which masks Indonesian personal data (UU PDP) before it reaches an LLM.

```text
/plugin marketplace add lokal-id/lokal
/plugin install lokal@lokal
```

Also on npm ([`@lokal-id/core`](https://www.npmjs.com/package/@lokal-id/core), [`@lokal-id/mcp`](https://www.npmjs.com/package/@lokal-id/mcp)), PyPI ([`lokal-id`](https://pypi.org/project/lokal-id/)), and the [MCP Registry](https://registry.modelcontextprotocol.io) as `io.github.lokal-id/lokal`.
